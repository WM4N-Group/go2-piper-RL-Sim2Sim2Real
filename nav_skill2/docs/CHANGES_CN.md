# Nav2 版本变化

V3及更早段落保留当时的历史诊断状态，不代表当前outputs库存。V3用户训练后来达到1200轮，已从冻结V3源码恢复继续训练；V4是独立的新训练配置，不改旧权重。

## symmetry_speed_v4（2026-10-22，当前新训练）

基于V3增加软镜像平均动作损失0.05（200轮渐入）；初始std恢复0.6，500～4000轮降低探索上限和熵；前进课程0.3～1.0m/s、原地转向0.2～0.6rad/s，后退/侧移单独设范围。站立/前进/后退/侧移/原地转向/混合采样比例改15/25/10/15/30/5%，回合末3秒平滑停车。超速容差改为指令幅值20%且至少0.05。

AMP从六类单速度改为九原片、方向加最近参考速度条件；判别器输入55→56维，状态转移数据3758条含镜像。新增前进0.8和左右转0.2参考，不含精确1.0或0.6参考。常规奖励权重、PD、限矩、观测315/324与12+6零动作合同不改。保留至少3秒承重预计算和2秒动作渐入，新增最长10秒、各环境独立收敛缓存；初始化倾角检查显式设为0.30rad（原因见CONFIG_CN.md），不改变运动姿态奖励。

V4需要从头训练，拒绝续训V3。旧V3权重保持不动，当前play按其原配置兼容回放。无固定接触节律、三足门禁或对称动作硬投影。测试和未验证项见VALIDATION_CN.md。

## V3兼容扩展：承重初始化（2026-10-22）

新增可选承重状态缓存与腿部动作渐入；新训练JSON开启3秒预计算、2秒渐入。旧checkpoint缺省关闭；网络、观测、动作顺序、PD、限矩、奖励、AMP、速度课程均不改，revision不变以保留正在运行的V3回放兼容。配置和源码哈希区分修订。

原因：贴地FK初始化只解决几何间隙；PD从零误差开始尚无承重力矩，加上第一步策略的大残差，出现下沉弹起。单纯0.8秒渐入不足，因此采用真实物理落稳状态和渐入组合。不硬锁腿，不抬高电机能力。当前用户长训练未停止；本修订只影响新配置训练或显式覆盖的测试。详细见STARTUP_DIAGNOSIS_CN.md。

## motion_amp_v3（2026-10-22，历史）

终端记录V2正式训练曾保存 `outputs/train-20261022-155814-94seumw2/model_1100.pt`。本次续接核对时，`outputs/` 已为空，不能声称当前仍有该权重；本次没有执行删除训练产物。修改前源码/配置/数据备份：`/mnt/miaojigui/artifacts/nav2-motion-v3-20261022/nav2-before.tar.gz`。V3仅做短工程检查，尚无长训练步态结果。

为什么改：V2的指数速度奖励在小指令下给静止策略很高分；AMP正奖励只看指令、不看实际运动。复查model800的GPU完整直行段，指令0.25m/s，4～19秒实际前向均速约−0.0007m/s，不能把存活当行走成功。

- 改为Climb/Extreme Parkour的实际沿期望方向运动比例，静止0分、反向负分，正奖励封顶。转向采用同样的有符号响应比例；不是照搬开源的目标yaw奖励。
- 课程从精确RMSE改为实际方向响应、持续运动和停车稳定；每个出现的行为分别检查，避免只会前进却掩盖完全不会右转。
- 加入固定WMP版本的真实后退、侧移、原地转向参考。AMP用行为标签条件判别，按类别匹配相位；镜像正确交换左右标签。
- AMP正奖励乘实际响应；不动仍付参考偏差成本。停车、跨reset/终止、跨行为类别转换不计运动AMP。
- 支持XY任意方向、后退、左右原地转向、运动中转弯；混合/斜向参考权重0.6，因为没有对应完整示范。
- 行走/转向权重改3/1.5；软横漂成本−1、明显超速成本−2；动作变化成本−0.03减到−0.015。探索std由0.6恢复1、熵由0.005恢复0.01，与Climb相近。
- 继续每100轮保存录像，自动覆盖前后左右、左右纯转及前进左转7案例，各12秒，包含起停；手动回放默认25秒。

观测315/324、12腿输出加6零、默认关节姿态、PD、真实电机限矩、延迟、贴地初始化和物理随机化保持原合同。Climb/Push/旧Nav文件不修改。

V3判别器增加类别输入、数据集和奖励/课程已变。禁止直接续训V2；版本检查在启动物理仿真前拒绝。旧权重需要使用对应输出目录中的原配置/源码回放，不可直接交给当前V3入口。

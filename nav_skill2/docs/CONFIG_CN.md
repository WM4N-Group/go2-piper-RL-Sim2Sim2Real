# Nav2 V4：参数与训练逻辑

当前版本 `nav_skill2_symmetry_speed_v4`。参数入口是 [configs/nav.json](../configs/nav.json)，定义位于 `tasks/direct/nav_skill2/parameters.py`、`agents/ppo_cfg.py`。本版需从头训练；不能将V3权重直接续训成V4。V3权重仍可通过play读取原配置回放。

## 输入、输出与物理

底层输入机身速度 `[vx,vy,wz]`，+X前进、+Y左移、+wz左转；上层到点导航未实现。Actor观测是5帧×63=315维：角速度3、投影重力3、相对默认关节角18、关节速度18、上一执行动作18、平滑速度指令3。角速度×0.25、关节速度×0.05。Critic324维，额外线速度3、接触4、实际附加质量/摩擦2。没有目标点、地形扫描或深度图。

Actor/Critic为512/256/128、ELU。网络只预测12维腿动作，补6个零得到18维接口；动作是默认姿态上的关节位置残差，尺度0.25rad，最大偏移±0.9rad，网络均值通过3.6*tanh(raw/3.6)限制幅度。概率、探索仅针对12腿。机械臂目标始终0，保留真实质量与重力，原臂重力补偿继续启用。

物理5ms、控制20ms（50Hz）；真实腿PD30/0.6，髋/大腿限矩23.7Nm、小腿45.43Nm，延迟0～4物理步。臂PD/限矩、共享USD、关节顺序未改。随机化每个环境创建时一次：基座附加0～1kg，静摩擦0.6～1.0，腿Kp/Kd独立0.9～1.1倍。没有提高电机力矩来掩盖不稳定。

## 速度与课程

| 等级 | 前进上限m/s | 后退幅值上限m/s | 侧移幅值上限m/s | 转向幅值上限rad/s |
| --- | --- | --- | --- | --- |
| 0 | 0.40 | 0.25 | 0.20 | 0.30 |
| 1 | 0.55 | 0.30 | 0.25 | 0.40 |
| 2 | 0.70 | 0.35 | 0.30 | 0.50 |
| 3 | 0.85 | 0.40 | 0.35 | 0.60 |
| 4 | 1.00 | 0.45 | 0.40 | 0.60 |

- `minimum_forward_speed=0.3`、`minimum_backward_speed=0.15`、`minimum_lateral_speed=0.15`、`minimum_yaw_rate=0.2`。这些下限约束纯方向持续采样；停止为0，起停平滑经过低速，混合方向的单轴分量可更小。
- `speed_limits`控制前进/XY总范数；`backward_speed_limits`单独限制负vx；`lateral_speed_limits`限制vy。混合采样在相应椭圆内，不能同时取各轴最大值。
- `command_fractions=[0.15,0.25,0.10,0.15,0.30,0.05]`：停车/前进/后退/侧移/纯转/混合。左右随机等量；每4～6秒重采样。
- `acceleration_limit=0.5m/s²`、`yaw_acceleration_limit=1rad/s²`，指令连续改变。
- `episode_seconds=25`，`terminal_stop_seconds=3`：最后3秒给零速度练减速和停车，不锁腿、不重置位置。手动play使用自己的起停时间，不强制应用训练末尾停车段。

课程门槛保持V3：完成运动且统计≥100个有效步、运动≥2秒、方向响应均值≥0.45、合格比例≥0.55；回合中出现且样本≥25的每个方向响应≥0.30；停车足够长时超出0.1m/s或0.2rad/s的坏样本≤30%。连续3个合格回合升一级，连续3个运动失败回合降一级。纯站立不升级。**尚未将独立确定性回放硬接入课程升级**，避免未校准门槛再次卡死；每100轮分别输出确定性方向/停车/超速评估，不能用平均训练reward声称全部方向合格。

## 镜像损失：针对左右不一致

`learning/symmetry.py`将整段历史观测镜像：FL↔FR、RL↔RR，hip外展量取反；角速度(-,+,-)，重力(+,-,+)，指令(vx,-vy,-wz)。臂零位关节轴根据共享USD核对，关节符号(-,+,+,-,+,-)，实测轴见[SYMMETRY_AXES.json](SYMMETRY_AXES.json)。观测关节量是相对默认姿态，默认左右hip本来相反，镜像后仍匹配。

损失 `mean((actor(M(obs))腿 − M(actor(obs)腿).detach())²)`。只监督策略均值，不对随机采样动作做镜像监督，也不把镜像样本伪装成PPO轨迹。`symmetry_weight=0.05`，前`200`轮线性渐入。允许改为0作对照。保留Piper载荷与接触造成的真实不对称修正空间；不规定左右腿同时运动、固定小跑节律或三足支撑。

## 探索与PPO

| 参数 | 值 | 意义 |
| --- | --- | --- |
| initial_std | 0.6 | 12维残差采样初始标准差，对应约0.15rad关节目标扰动 |
| exploration_anneal_start/end | 500 / 4000 | 按累计轮数渐变，续训恢复轮数不会重新开始 |
| final_std_max | 0.25 | 后期可学习std的上限；下限仍0.1，不突然清零探索 |
| entropy_coefficient → final_entropy_coefficient | 0.005 → 0.001 | 同期线性减弱维持探索的奖励 |
| steps_per_env / epochs / minibatches | 24 / 5 / 4 | 每轮采样、PPO遍历和分批数 |
| learning_rate | 0.0002 | 按目标KL0.01自适应，范围1e-5～5e-4 |
| gamma / gae_lambda / clip | 0.99 / 0.95 / 0.2 | 回报折扣、GAE和PPO裁剪 |
| value_coefficient / max_gradient_norm | 1.0 / 1.0 | 价值损失权重与梯度裁剪 |
| iterations / save_interval | 15000 / 100 | 默认总训练轮数与保存录像间隔；CLI iterations为本次额外轮数 |

只修改噪声上限与熵退火，保留原PPO采样概率与超时终态bootstrap。日志增加symmetry_loss、有效symmetry_weight、std_cap、entropy_coefficient和各方向实际响应。

## AMP：按方向和速度匹配

`amp_dataset=amp_speed_pairs.json`，`amp_speed_conditioning=true`。源码在`learning/amp.py`；数据转换在`scripts/prepare_amp_data.py --speed-conditioned`。固定WMP提交`65cf1afd13e4792bce7b9def6f44372ecbb3cdf0`，9段原始数据均逐个SHA256验证，来源和保留帧索引写入数据JSON。

实际使用：前进0.4/0.8m/s；后退0.4；左右侧移0.5；左右转0.2/0.5rad/s。先按方向，再按**平滑指令幅值**选最近速度组；判别器真假样本在同一方向、同一速度组配对，输入增加所选速度条件。参考成本也限定在相同组。镜像样本正确交换左右标签、保留速度。切换方向/速度组、终止、reset、停止、动作渐入期不拼接运动AMP转换。

**没有恰好1.0m/s或0.6rad/s的示范**：分别使用附近0.8和0.5风格参考，由任务学习实际速度。没有纳入超出当前目标的1.3前进和0.8转向，也没有伪造重定时数据。来源是裸Go2公开片段，不是Piper载荷示范，不含接触力标签，混合/斜向参考权重仍0.6。

状态30维=q12+线速度3+角速度3+qd12，转换60维；判别器只看两帧q/qd48维、方向one-hot7和速度1，总56维，MLP512/256。四腿共享最佳参考相位，成本一半平均、一半最差腿。判别器奖励权重2、参考成本0.5、学习率1e-4、梯度惩罚10、batch1024、每轮4次更新、回放65536，均保留原值。正AMP奖励乘实际方向响应；站着不动不获得运动正奖励。

## 奖励与惩罚

除软超速余量外，权重保持V3。每步加权和乘0.02秒，失败额外−5。

| 项 | 权重 | 作用 |
| --- | --- | --- |
| velocity / yaw_velocity | +3 / +1.5 | 实际沿指令运动比例；静止0，反向负，达到指令后正奖励封顶 |
| direction_drift / overspeed | −1 / −2 | 横漂、无指令自转；超过容忍带的速度平方成本 |
| stationary / standing_posture | +2 / −1.5 | 零指令时奖励低速度，软约束腿部默认站姿 |
| upright / base_height / vertical_velocity | −2 / −1 / −0.5 | 机身倾斜、偏离0.30m高度、竖直晃动 |
| roll_pitch_rate / action_rate | −0.1 / −0.015 | 俯仰横滚速度与关节目标突变 |
| joint_acceleration / torque | −2.5e-7 / −1e-5 | 关节加速度与力矩平方 |
| foot_slip / collision | −0.3 / −1 | 承重足水平滑动、非法身体接触 |
| joint_limit / arm_error / flight | −2 / −5 / −0.5 | 软关节越界、臂偏离零位、四足全腾空 |

软超速允许量=`max(0.05, 0.2×指令幅值)`，线速度和角速度分别计算；是惩罚而非速度硬截断。停止时也保留0.05容忍，不要求逐毫秒精确跟踪。

## 初始化、终止与兼容

`reset_settle_seconds=3`：创建环境时用真实物理建立承重状态，缓存每个环境实际q/根高/姿态，reset恢复并清零速度；PD目标保留默认值以保留承重力矩。`startup_action_ramp_seconds=2`：腿部动作和探索按10x³−15x⁴+6x⁵渐入，不锁机身。原`startup_seconds=0.4`与`command_ramp_seconds=0.6`继续平滑速度。静态准备的支撑检查不作用于行走步态。

倾角>0.85rad、根高<0.15m、机身/臂非法接触>8N、臂角误差>0.35rad持续0.3s为失败。25秒超时保留终态bootstrap；没有上层任务到点成功终止。

缺失的新字段保留V3缺省行为。V4改变训练损失、课程范围和AMP条件维度，需重新训练；V3回放可用，V3续训用对应冻结源码与旧数据。Climb、Push、旧Nav及共享机器人资产不修改。

承重预计算参数补充：`reset_settle_seconds=3`为最短预计算时间，`reset_settle_max_seconds=10`为未收敛时的上限。各随机化环境分别检查实际线速度低于0.05m/s、关节速度低于0.3rad/s、姿态、支撑和非足部接触，分别缓存自己的收敛状态，避免要求所有环境同一时刻恰好静止。只在环境创建时运行，不占策略回合；未收敛时报出实际指标并拒绝训练，不放宽条件掩盖问题。

`reset_settle_max_tilt=0.30rad`（约17.2°）仅是预计算状态的允许倾角，不是运动奖励或硬姿态限制。2048随机环境检查发现1个环境的静态平衡倾角约14°，四脚承重、速度0.0013m/s、关节速度0.028rad/s且无机身接触；原先固定0.15rad的检查会误拒绝整个训练。因此改为显式0.30rad门限，同时保留接触和速度检查。该极少数静态倾斜应单独观察，不能宣称所有随机环境起步都水平；无随机化回放的起步倾角约1°。实际行走姿态奖励、跌倒判定、PD和随机化范围不变。

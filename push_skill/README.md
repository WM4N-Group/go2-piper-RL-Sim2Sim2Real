# Push：权重回放与录像

本目录只提供原 v212 的预训练策略回放，不训练。原始完整包在 `../history/skills/push/v212/`。新的入口不复制训练树、不加载影子观察器、不逐步保存大规模诊断；默认单环境，640×480，25fps。物理200Hz、控制/策略50Hz不变，物理和策略使用GPU；精确碰撞距离查询仍在CPU执行，不能删掉这个保护来提速。

## 运行

```bash
conda activate go2-piper
cd /mnt/miaojigui/zyh/push_skill
python play.py --headless --device cuda:0 --video
```

每次自动新建 `outputs/play-时间戳/`，包含 `push.mp4`、简短 `report.json` 和 `startup-report.json`。录像持续到完整回合成功、失败或48秒超时，再加2秒明确标注的静态结果卡；失败会显示失败，不再把10秒截断当作任务完成。退出码0代表本次成功，2代表本次任务未成功；异常保留报告并报错。没有收臂阶段的成功不能称为已完成收臂。

```bash
# 更少渲染开销，物理控制频率不变
python play.py --headless --device cuda:0 --video --video-fps 10
# 恢复原自由空间入场速度
python play.py --headless --device cuda:0 --video --arm-speed 1
# 不录视频，不启用虚拟摄像机
python play.py --headless --device cuda:0
```

`--video` 启用的是 Isaac 的虚拟渲染相机，不调用服务器上的真实摄像头。启动 Isaac 和加载 USD 本身有固定开销；减少录像帧数不能消除初始化时间。

## 文件作用

| 文件/目录 | 作用 |
| --- | --- |
| `play.py` | 加载两个权重，运行完整回合，录制并报告真实终止原因 |
| `weights/model_199.pt` | 226维输入→12维冻结腿策略 |
| `weights/model_255.pt` | 226维输入→19维策略；回放使用末7维：6维臂残差与1维速度调节 |
| `policy.py` | 从原 checkpoint 构造 ELU 网络，不改变关节顺序/观测布局 |
| `control.py` | 原场景、接触、残差动作和安全终止配置；`SETTINGS` 是主要控制参数 |
| `startup.py` | 足底离地2mm开始真实承重落稳，不锁根部、不施外力；时间与结果标注 |
| `runtime/source/` | 配套环境、观测、IK、PD和几何保护的必要实现；不是另一个需要安装的项目 |
| `runtime/mujoco/deploy/piper_push_safe_approach.json` | 实际使用的两点入场关节路径；仅路径数据，不运行MuJoCo动力学 |
| `geometry/` | 原机器人几何与配置，仅用MuJoCo计算静态碰撞净空；动力学仍在Isaac中 |
| `../asset/go2_piper/` | 与Climb、Nav共用的机器人USD |

内部保留部分旧基类名称（`go2_arx5`/`LeggedManip_Lab`）用于维持原策略契约，不跨目录调用历史项目或Nav。删除这些名称并重写控制器有引入行为变化的风险，当前没有做这种重写。

## 场景、初始状态与提速

箱子1.2×1.2×0.2m，质量1kg，箱体静/动摩擦0.15，向+X推0.60m。机器人从原点后退8cm启动，六轴机械臂默认目标全零，腿与Climb默认角相同；先真实落稳，再开始任务计时。推进完成要求原 `box_settled` 成立：距目标小于0.12m、箱速小于0.08m/s持续0.5s，同时没有其他安全失败。回放不要求收臂。

不重训即可调自由空间入场倍率 `--arm-speed`，范围1～2。只在原关节路径尚未完成时放大限速，原60ms平滑、到位检查、净空、合法接触和电机上限仍生效。路径完成后接近箱面和推动不加速；倍率不保证动作全过程等比例变快。默认倍率及实测结果见根整理验证记录，未通过的提速配置不会当作成功发布。

原门禁包括：表面净空35mm、原IK身体点净空、原身体/箱体碰撞与合法手接触、臂力矩比例0.98终止等。没有提高真实电机能力，也没有降低原成功门槛。每次模型加载核对双权重SHA；交付代码和资产的校验见根 `SHA256SUMS`。

## 验证边界

此入口是精简、提速候选，不是新训练的策略；单次开发回放不代表正式批量验收或实机可部署。旧成功开发对照见 `../history/outputs/push-original-entry-backoff-20261020-c/`。技能切换、收臂接管尚未实现。

当前实测：1.5倍自由空间入场、GPU单环境、25fps，13.60秒仿真时间成功推移60.12cm，平面目标误差2.11cm，未触发原安全终止。完整录像15.64秒（含2秒结果卡）；含启动总耗时276.95秒，实际回放169.21秒。旧开发对照含启动341.88秒，二者不是严格性能基准。录像在 [本次回放](outputs/play-20261020-200038/push.mp4)，整理摘要在 [根验证记录](../REORGANIZATION_REPORT.json)。

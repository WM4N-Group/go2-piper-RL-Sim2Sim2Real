本目录独立运行前开发者的 PUSH。冻结的 `v212/` 原件保留；`run.py` 将其复制到新的输出目录，再应用 `startup.py` 的初始化和录像适配。**这属于新候选，不能沿用冻结版的成功率。** 不修改用户的 `push_skill/`。

## 文件与控制关系

## 当前初始化

1. 固定原默认关节初姿，关闭初始关节角0.5～1.5倍的随机缩放。
2. 默认把狗的起点沿世界−X后移 **8 cm**，箱子与目标不动。参数 `--start-backoff 0.08`，范围0～0.15m；用于给原机械臂入场下降路径留出箱沿净空。
3. 从USD读取足底球半径/中心，把最低足底放在地面上方2mm，再由原PD真实承重。原最低足底实际仅离地约6.5mm；明显下沉还包括承重压缩，不能全归因为自由落体。
4. 最多5秒准备，全部环境四脚接触>3N、机身速度<0.035m/s、角速度<0.12rad/s持续0.3秒才允许继续。
5. 保留承重关节状态，将XY放回本次设定的起点，再运行0.5秒复核；XY误差须<1cm。随后刷新控制器参考与观测历史，任务计时开始。

这是reset准备，不锁根部、不添加外力、不在推动过程中瞬移。`startup-report.json`记录实际间隙、初始/承重高度和速度。只适用于当前平地，不代表无reset技能接管。`--original-start`关闭准备和后移，用作旧初态对照。

## GPU运行与录像

```bash
conda activate go2-piper
cd /mnt/miaojigui/zyh/skills/push
python verify.py
python run.py --gpu 0 --num-envs 1 --video-fps 10 \
  --output-dir /mnt/miaojigui/zyh/outputs/push-demo-002 --execute
```

输出目录必须新建，不覆盖旧结果。省略`--execute`只准备。默认8环境；只看单个演示用`--num-envs 1`，不能将它冒充原8环境批次。seed保持3701。

录像默认10FPS，可选5/10/25；只改变渲染/录像，物理仍200Hz、控制仍50Hz。`--no-video`完全关闭摄像头；`--startup-only --num-envs 1`只检查初始化。GPU物理不消除CPU几何检查、同步、诊断和Isaac加载开销，不能保证实时。实际子进程耗时写入`exit-status.json`的`wall_seconds`。

任务预算仍48秒：成功、失败均可提前结束。视频顶部显示仿真时间，结束追加**2秒明确标注的静态结果卡**，列出成功数和终止原因，不把静帧当仿真或稳定时间。不能为了录满48秒而屏蔽失败。

输出包括`report.json`、`video.mp4`、`run.log`、`run-plan.json`、`startup-report.json`、`exit-status.json`。每200步日志输出实际手位置及高度/推面门控状态。**退出码0不代表成功，检查report的成功、失败、缺失回合。**

## 参数与判据

原场景：箱子1.2×1.2×0.2m、1kg、摩擦0.15，目标推进0.60m；当前只调整狗的初始距离。成功要求目标误差<0.12m、箱速<0.08m/s持续0.5s，并满足原接触与安全条件。实机及正式跨仿真验收未完成，见[项目PUSH交接](../../docs/PUSH_CURRENT_HANDOFF_CN.md)。
